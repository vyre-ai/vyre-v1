A document is never sent for signature in a version the exact-copy check did not see: the check says which version and bytes it was about, and if a new version is uploaded while a send is under way, the send is refused and nothing goes out. The send does not read the file an extra time. Making a PDF and the signing answer are no longer separate agent tools (documents_make takes format pdf), and a few documents and e-sign tool descriptions are shorter.
