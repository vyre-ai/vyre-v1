The Fields panel can now link a record type to another: Add field, then Link to…, pick the type (for example Contacts). Both ends are made, so the Contact page lists its Deals. A new "Check for sensitive data" link scans the type, names the fields that look like ID, card or bank numbers or health data, and marks each one restricted or confidential with one press. The panel also says that three or more groups show as tabs. Sealing a field is not offered yet: the schema module cannot seal values already stored, and a sealed field cannot take a value until the Vault is wired into Records.
