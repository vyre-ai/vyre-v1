- Every person now has a private assistant from the moment their account exists: the owner at claim, a member at join. It exists before any AI account is connected, so the console assistant no longer answers "Connect an AI account first" for a missing agent. The consumer `agents.ensure_assistant` reads `principal.created`, makes one agent owned by that person (named "<first name> Assistant", with a numbered fallback when the name is taken), and a repeat delivery finds it and does nothing.
- The assistant is private to its person: other people, including the Space's admins and anyone with a view grant, do not see it in any list, cannot get it, @mention it or open a chat with it (the agents module answers "not found", as for any agent a person may not see). The lookup that keeps a second delivery from making a duplicate and the one the Console assistant uses both read the same role the assistant is created with.
- Chat now asks the agents module before it brings an agent into a chat or an Ask, or accepts an @mention of one: an agent the person may not see (another person's assistant is one) is answered "not found", the same as an agent that does not exist.
