- An agent computer that runs on a person's own computer (one that joined the Space) can now be watched, taken over and recorded from the Space. The node holds one outbound socket to the Space (`/compute/stream`); a viewer's one-use ticket is bridged onto it at `/computers/<id>/stream` (MJPEG) or `/computers/<id>/ws`. Input flows only for a take-over ticket while the person holds the controls; a removed node's sockets close at once; a node can only serve the computers the register places on it.
- Recordings on a node: start and stop are jobs, the finished folder (video, events, network log) reaches Files through the upload slot, and process, get and delete work as at home. Delete clears the node's copy and the Files copy.
- Fixed: a node's home mirror could not send a large file (over 256 KB) because `put_upload` was missing from the calls a job token may make; the limit for an upload to a slot is now 48 MB.
- The computer popup says "on <computer name>" for a computer that lives on a node.
