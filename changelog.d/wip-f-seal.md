- Saved browser sign-ins are now locked on the server while nobody is using them. An agent computer's browser profile (cookies, saved logins, history) is encrypted and taken off the Docker volume when the computer sleeps, and put back when it wakes. Each agent's browser in the Space browser is locked the same way as soon as its browser goes idle, and unlocked by its next step. A copy of the volume or of Docker's own data holds nothing readable.
- If the server stops while a profile is unlocked, it is locked again at the next start, before the computer or browser can be used. A locked profile that was changed or cut short is never opened: the computer says so and does not start, and the locked data is left as it was. Profiles from before this update keep their sign-ins and are locked at the first start or the first sleep.
