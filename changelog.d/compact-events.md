New command `vyre-server compact [--check] [--yes]` for a planned stopped window: it builds a new events.db without the kept answers of read calls (connectors.read), a file that gives free pages back in steps, checks it (every table counted against the old file, the newest event and its hash compared, quick_check), puts it in place with the old file kept until `vyre-server compact --finish`, and puts the old file back if the server does not come up healthy.
