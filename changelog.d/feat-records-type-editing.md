Records can add and edit record types and fields without the Console. A plus by the type list and New record type under Manage open a small sheet (name, plural, icon; the key is made from the name). The table Fields button opens a panel to show or hide, add, rename, change the type of, reorder and delete fields, with Recently deleted and Restore. Record types has a more menu per row (Rename, Delete type). Each change is previewed with schema.diff and applied on that exact preview; a destructive one asks once with the row count. Shown only to people with the Console schema permission, and to the owner of a Personal Space. Menu items can now be disabled with a reason on hover.
