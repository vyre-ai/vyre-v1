- Models: Codex, Claude Code and Grok now list the models your own account offers, the same list their own apps show. Vyre asks each engine for its list in your sandbox with your sign-in, saves it per account, and refreshes it when you open the model menu and once a day. The menu opens at once on the saved list, then shows the fresh one with "Updated just now". If a refresh fails it keeps the saved list and says "Couldn't refresh, showing saved list". A new model shows up as its own row under the vendor's name, with the vendor's default marked Default. A pick saved under an engine's alias (opus, sonnet) stays on the model that alias means today. Models that ran out of usage are still greyed.
- Models: each release ships the current model list for every engine (GPT-6.1-Sol and the rest for Codex, Opus 5.5 and the rest for Claude Code, Grok 4.6 and 4.5 for Grok), so a fresh install with no network still offers current models. The old lists (gpt-5-codex, grok-4) are gone.
