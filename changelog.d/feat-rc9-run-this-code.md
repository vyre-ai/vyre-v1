A one-line shell block in a chat message now has a Run bar: a dot for what the command can do, a chip for the machine (this computer, the Space server, an agent's computer) and Run. A command that only reads runs at once and shows its output under the block. Anything that changes something, or is destructive, is typed into that machine's terminal for you to read and send with Enter, and your own deny rules still stop a command before it reaches the machine. Blocks with more than one command have no Run, so a newline never runs the first line unseen.
