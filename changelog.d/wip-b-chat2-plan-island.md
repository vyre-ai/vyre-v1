- A plan an agent proposes is now a card headed "Plan" with its steps and ticks that fill as the work goes on ("2 of 4"), and the buttons Allow, Change it and Deny. Change it declines the plan, and only when that went through puts it back in the message box as a draft you can edit; if the decline fails the plan stays waiting and the card says so. Removing steps from a plan is now done by editing that draft.
- A small pill above the message box says "Thinking" or "Writing" (the same word the reply line shows) with the faces of everyone working (and a computer glyph while the agent runs a command or drives a browser), whenever any agent is at work, not only when helpers exist. Pressing it opens the crew; it steps aside while a question is open.
- The message column no longer carries the "Times here use ..." line (it is at the top of the chat's menu). "No agent will reply. @mention one" now sits once, quietly, under your newest message that nobody will answer, and goes when an agent is mentioned or answers.
