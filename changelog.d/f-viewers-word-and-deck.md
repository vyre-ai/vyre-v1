A Word file opens in Files as its page, with headings, fonts, lists, tables, pictures, links, page breaks, header, footer and footnotes; in Edit you can type into it and make text bold, italic or underlined and set a heading, and the change is saved as a new version of the same file with everything you did not touch left exactly as it was (a paragraph with tracked changes, a content control or a field is kept as it is and marked). A PowerPoint file opens as slides with a filmstrip, Find across slides, comments pinned to a slide, Present full screen with the arrow keys, and typing into a text box or table cell is saved back the same way. A connected Drive or OneDrive file goes back as a new revision of the same file; a file Drive locks is view only.
