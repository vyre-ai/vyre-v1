- Agent workspaces: every agent (and so every person's Assistant) gets a small container of its own, made the first time its terminal is used, with no grant. It holds a shell, tmux, git, node 24, python and the usual tools, runs as a user that is not root with no Docker socket and no setuid program, sleeps after ten idle minutes with its files kept and wakes in about a second. The image is images/agent-workspace and is released like the agent computer image (VYRE_WORKSPACE_IMAGE in images.lock, compose.env, the server compose file and the compute-node compose).
- An agent's terminal_run, terminal_open and terminal_request now go to its workspace whichever computer its turn runs on, and the terminal tab attaches to the same tmux sessions. A person opens their own Assistant's workspace; owners and admins open a team agent's; no one opens another person's Assistant.
- Placement: an agent that has a computer is no longer pulled onto the Space server. Its turns keep own-computer-first, and its workspace and browser are reached over the Space.
- The Files folder: ~/Vyre in a workspace mirrors the agent's folder in Files (the same sync agent computers use, run as the agent), down before the first command, every few seconds while awake and once more before the workspace sleeps. A file the agent makes there shows up in Files.
- Shared project folders: each project the agent is on is one shared volume, mounted in every member agent's workspace at ~/projects/<project>. The sites runner now also judges workspace containers, their network and project volumes, and refuses anything outside that profile.
