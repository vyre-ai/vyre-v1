A record shows everything about it. The record page's side pane opens on a new Everything tab: its edits, comments, emails and texts, files, tasks, runs and chats in one list, newest first, each with what it is, one line and how long ago. A task, run, chat or file opens where it lives. Each part is read as you, so what you may not see is not there and nothing says it was left out; mail from a private mailbox never joins a record's history. Fixes along the way: conversations and mail messages are now registered in access when they are created (and an older Space's conversations at start), so opening one by id no longer answers "not found" to everyone.
