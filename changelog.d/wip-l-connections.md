- Vault > Connections is the one home for every connection (owner ruling D28): built-in integrations, MCP servers, app hubs, and the servers plugins and skills bring, in one list. Mine is for you and your agents; Space is for everyone or the groups an admin picks. Each row has a steady health dot, who can use it, which agents used it and when, and Test, Sign in or Reconnect, Share, Turn off and Remove.
- Add a connection from the official MCP Registry (searched as you type, and from the last fetch when offline), from a pasted address or command (npx, uvx), or from a Claude Code or Codex config (.mcp.json, ~/.claude.json, ~/.codex/config.toml). Keys go into the Vault (your own folder, or a shared one for the Space) and never into a command line; the connection is checked as soon as it is added, and a server that signs in with OAuth gets a Sign in button.
- Each connection's health, tool count and last use are recorded as agents use it, so the dot on the page matches what the agents saw.
- A person can add and sign in their own connections; a Space connection shared with groups reaches only their members.
- Admins set who may add Space connections and can turn on an allow-list (registry names, hosts or packages) for everyone else, on the Vault page.
- Settings > Connected and the Console's Plugins page show a short summary with Open in Vault; the app hub card and the outside tools form moved to the Vault.
