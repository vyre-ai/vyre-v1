- The Linux and Mac installers read the signed release feed from the GitHub release of the chosen channel (stable: the newest release, beta and nightly: the rolling `channel-<name>` release) instead of `https://vyre.run/server/`, which nothing serves. `VYRE_UPDATE_URL` still overrides it, and `vyre-server` falls back to the same stable feed when an install has no `update-url` file.
