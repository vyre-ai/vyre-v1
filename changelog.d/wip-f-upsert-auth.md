- A bulk upsert (an import, an agent tool call, a source delivery) now changes an existing record only when the caller may edit that record, and a merge needs the rights to delete every record merged away. A row the caller may not change, or a locked field, is reported for that row and the rest of the batch is written; an import counts such rows as failed. What an update replaced is kept with empty fields as empty, so Undo can clear a value an import filled.
