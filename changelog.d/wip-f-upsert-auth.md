- A bulk upsert (an import, an agent tool call, a source delivery) now changes an existing record only when the caller may edit that record, and a merge needs the rights to delete every record merged away. A row the caller may not change, a change that needs approval, or a locked field is reported for that row with the reason and the rest of the batch is written; an import lists such rows as failed with the row number of the file, and a source delivery that hits one is kept as failed with the reason so it can be processed again.
