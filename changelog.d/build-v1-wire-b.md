- Records: the Calendar, Timeline, Map and Charts views are in the view switch (and a link can name one with kind=), and Record types and the Schema map open from the sidebar's Manage rows.
- Files: Review changes opens the change set in the Files body with its header, git row (and its Gate) and diff; a compare, a commit and a history open the same way; an agent's AGENT.md and agent.toml open as the agent file page with the lint bar and the agent.toml Form; Ask about this file starts an Ask pane.
- Chats: Ask about this file and Change by Asking put their text in the composer; the sidebar dot says when another Space needs you. Token streaming is not wired: the engine posts a reply once, when the turn ends, and clients receive no deltas.
- Inbox: Match to a record opens the Unmatched screen; the conversation shows the call bar and the after-call strip when the phone is on that contact; the Calendar's free and busy menu lists the Space's people; Templates are the Space's email designs (and the composer's / menu lists real snippets) with a Design a template row that opens the email builder.
- Vault: Ask an agent starts an Ask pane on the item; an export asks for a link that lasts 1 hour, 1 day or 7 days; Advanced has a Policy page (who may export, the longest link, whether a reveal asks why).
- Settings: Sign-in and devices shows the password's age, GitHub, authenticator app, second-factor floor, single sign-on and devices (new read identity.security.get); Choose a photo keeps the image in the person's own files.
- Report a problem works on a server: the host supplies the bundle sources and a signed client for reports.vyre.run (reports.resolved, the inbound webhook, stays deferred).
- Apps: one email design opens on its own (New email design, and from the Inbox Templates menu).
