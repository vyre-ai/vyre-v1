Tagging an agent onto a message that was already sent is now proven end to end: Ask an Agent, the clickable "No agent will reply" line and an edit that adds an @mention each make the agent answer once, on the account of the person who asked, and never again on later edits. New tests drive the edit through the conversation and run it on a real Space.
Ask the Space is in the top search. Type a question in Cmd-K and an Ask the Space row appears (first for a question, last for a plain phrase). Press Enter and the question stays in the field while the answer is written under it with numbered citations that open the source, a Sources list, Copy, and Continue in a chat, which opens a real chat with the question and answer. Esc goes back to the results and typing leaves the answer. The answer is made only from the chats, records, files, tasks and notes the person may read, runs on their own AI account (their own first, else the Space's they may use), never uses the private profile, and says "I can't see anything about that you can read" when there is nothing to read.
Search no longer shows an invite-only channel or chat to a manager who was not invited. The Space-wide view grant covered it before; a chat result now also has to be one the person can open in Chats.
