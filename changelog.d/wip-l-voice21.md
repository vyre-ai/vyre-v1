## What's new
- Talk (the mic in every message box) is in. One Deepgram key for the whole Space is kept as a Space-shared Vault item that admins add in Console, Voice; nobody can read it back and it never reaches a client. A person's own key in Settings, Talk covers them first.
- In a team Space where nothing covers a person, pressing the mic says "Voice isn't set up. Ask an admin to add a key." instead of asking a member for a key. An admin also gets a link to add one in Console.
- Settings, Talk has the on and off switch, language, model and your own key.
- Talk works in the new chat field. Spoken words go in at the caret, a mention chip before or after them stays one chip, and one Undo takes back everything you said in that go.
