- An outside agent that reaches something only a person does here (sign-in, invites, access, the company connection, the engineer tools) now asks the person it acts for instead of stopping. The person gets an approval card that says what will happen, which agent asked and every input, with secrets shown only as Vault handles. Approve runs it as them, once, exactly as shown, and the agent gets the answer. Decline tells the agent it did not run. If the person cannot do it either, the agent is told an owner or admin has to.
- An outside agent that wants a key in the Vault now asks for it by name. A person pastes the value in their own app, and the agent gets the key's name to use as a handle, never the value and never access to it.
- When you connect your own agent (Claude Code, Codex, any MCP app) as an owner or admin, you can let it act for you, including setup: sign-in and SSO, Connect your company, the Space's AI key, Vault items, invites and Console settings, with no card. Your own rights are checked on every call and the audit log names the agent. Sends, posts and payments still follow your rules, and it can never read a secret back. Turn it off any time in Settings > Outside agents; an admin can turn it off in the Console.
