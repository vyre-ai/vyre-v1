- Share adapters (apps/app/src/share/adapter.ts): one typed adapter per item type (Notes, Vault items and folders, Files, folders, artifacts, records, record types, projects, agents) for the shared Share sheet. Each lists who has access, sets a level, removes, and offers only the levels the person holds. access.shares_of now returns the caller's own level (`mine`).
- Agent Share sheet (Dex, owner report 4 Nov): the Agent form opens the shared Access sheet. An item never lists itself, a person is one row at their highest level, the owner is one Owner row, General access ("Everyone in the Space") is one row at the top, other people's Assistants and private agents are never named (the server leaves them out of access.shares_of), agents get one "Agents in this Space can call X" line, inherited rows say "From the Space" when there is no folder, the legend paragraph is gone, each level shows a one-line description in its menu, and the count behind the sheet comes from the same deduped list.
