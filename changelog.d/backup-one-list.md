Backups from `vyre-server backup`, before an update and before a restore now show in the Console's backup list beside the ones Vyre takes itself, and Back up now works on a server where nobody has chosen a place yet. It writes to a folder on the server's own disk and says so in the list, with a reminder to choose an off-site place or copy it away. Before, the button answered "Choose where backups go first" and the list stayed empty. A manual backup is also never rotated out any more, however many you take.
