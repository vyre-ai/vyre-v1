Backups from `vyre-server backup`, before an update and before a restore now sit in the same folder as the ones Vyre takes itself, and show in the Console's backup list beside them. You can check one and delete one there; restoring one is still done on the server with `vyre-server restore`, and the Console says so. Back up now also works on a server where nobody has chosen a place yet: it writes to that folder on the server's own disk and says so in the list, with a reminder to choose an off-site place. Before, it answered "Choose where backups go first" and the list stayed empty. A manual backup is never rotated out, however many you take. An existing server gets the shared folder on its next start or update, with its logins kept. The folder is 0700 and each backup 0600 and owned by the server's user, who must read them to list and check them: a backup holds the Caddy certificate keys as well as the Space, so anyone who can act as that user on the machine can read them. The copy taken before an update or a restore cannot be deleted from the Console; the server keeps it as the way back.
