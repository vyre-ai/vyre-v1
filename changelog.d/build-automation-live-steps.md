- feat(automations): an HTTP request step. Every request and redirect goes through the public fetcher, capped at 1 MB and 30 s. A Vault handle signs it as a bearer token, basic sign-in or named header, filled by the Vault for one call and scrubbed from the response, the log and the output.

Where bwrap is missing the step is hidden, turning the automation on is refused with the reason, and the code never runs in the daemon.

It can run as an agent, validates an output JSON schema and fails by name on a mismatch, holds the answer for a reviewer or approver, uses a recorded sample in a sandbox test, and is counted in usage and spend caps.
