- Word files open in the Files viewer as a document: headings, paragraphs, bold and italic, bullets nested by level, numbered items, tables with their header row, and a marked place for each picture with its alt text. Before, every paragraph and table cell was a plain line, so headings and tables were lost.
- PowerPoint files open as a run of slide cards, each with its number, title, body, tables, pictures and speaker notes. Before, a deck opened as "This file is empty".
- An agent's `files.read` of a Word file returns Markdown with the same structure, and of a deck one `# Slide n: Title` block per slide with its notes. `previews.text` for one page of a deck returns that slide.
- A Word, PowerPoint or OpenDocument file opens read only, under the same DOCX or PPTX tile as in the file list (older .doc, .xls and .ppt files now wear these tiles too). Before, a Word file offered an Edit switch whose changes could not be saved.
- A Word or PowerPoint file Vyre cannot read shows "No preview of this file here. Open in Word to see it." (or PowerPoint), beside the Open in Word button when the file comes from SharePoint or OneDrive. This covers a password-protected file, a damaged one, and an old .doc or .ppt when the server has no converter. It never shows a blank page.
- `files.read` refuses such a file with a message an agent can act on: "This file is password-protected, so its text cannot be read. Open it in Word." Before, it returned an empty string, or for an old .doc the raw bytes decoded as text.
- An old .doc, .xls, .ppt, .rtf or OpenDocument file from a mounted folder is recorded as that type, no longer as text/plain. Reading a file that an earlier version recorded as text/plain now goes through extraction too.
