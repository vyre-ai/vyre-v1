- Only one "go back" runs at a time for an agent in a chat ("Going back is already running here."). While one is going back, a message to that agent waits, with one line saying so, and starts by itself when it finishes; a rewind that makes no progress for minutes is given up on and listed on the chat with Undo.
- A source file is no longer kept out of Rewind because its name contains a word like token, key or env: only names and extensions that really mean a secret are, and a file of any other name is judged by what is inside. The card says a secret in a text file over 256 KB or in a file that looks binary is not recognised.
