Vault and Console, second pass. Console create forms are no longer open on the page: Agents, Outside actors, People, API keys, Incidents, Skills, Holds and Agent computers each have a "New ..." button in the section header that opens the shared sheet, and model fields are a model picker built from the Space's model list instead of free text. Agent rows have an ID-based avatar and a status dot with a capitalised word. Server logs has Server logs, Services and Storage as tabs, a level picker and one Filter row that opens a sheet. Sessions, Usage, Network, Diagnostics, Speed and every other Console page have their own icon. Help sentences moved into hover tooltips (a small info mark), and a disabled button gives its reason as a tooltip instead of a line beside it, in the Console and the Vault (Add, Save, Policy). Vault Policy now fits a readable width and has no search shortcut hint on a phone.
