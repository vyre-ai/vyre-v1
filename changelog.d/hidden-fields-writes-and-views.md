A member whose grant hides a field of a record no longer gets the hidden values back from the writes that answer with the record (update, restore a version, update many, relate, review a value, merge, restore) nor from a saved view of the type; and a guard test walks the manifest so a new capability that returns a record row cannot slip past the filter. A write that moves a record out of the member's view (a row filter on their grant) is answered with no fields, and stays done: an empty record in an answer is not a failure.
