Every project now has its own folder in Files under Projects. A project made any way gets one (a name clash takes "Name 2"), the folder is renamed with the project, goes to Trash with it and comes back on restore, and it is opened to the same people as the project. At start, project records that never had a project behind them (such as an old "Test") are adopted: they get a folder, a channel and roles. On the project page the Folder field is a link into Files and the Files tab lists the folder's contents.
