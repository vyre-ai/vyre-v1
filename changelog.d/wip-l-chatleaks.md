- Chats: when an agent @mentions another agent, the second agent now runs for the person who asked, on their account and with their access, never for whoever started the chat. An agent's message with no person behind it no longer runs as anyone: the chat says no one asked for it.
- Chats: two agents on a coding engine (Claude Code, Codex, Grok) working for you in the same chat each get their own work folder, so neither reads the other's memory notes. A shared folder beside them is the one place both can reach.
- Memory: in a chat other people read, no memory tool returns your own memory any more (facts by date, notes, single facts, pages, lists, Trash, Learned, quotes by reference and the "what the agent knew" view included). Shared memory from an agent, a project or the Space comes back there only when everyone in the chat may open it, so a guest never hears a project fact through a teammate's question.
- Memory: what an agent learns in an invite-only channel or a chat with several people is kept for those people. It never comes back in a chat whose people are not all among them, and it stays out of the agent's memory map.
- Chats: what an agent's tools return during your turn is now yours alone. It is no longer part of the chat's shared transcript, so other people in the chat (in a public channel, the whole Space) cannot read it, search it, or find it in the chat summary. The agent still has it for its follow-ups with you.
- Chats: when you ask an agent something in a chat with other people and its answer uses a record, file, email or event that one of them cannot open, the agent sends you the answer privately, in your own chat with it, and tells the chat it did. While it works, its live text shows only to you.
