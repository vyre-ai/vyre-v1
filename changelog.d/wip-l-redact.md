- Redaction for AI, the read gate. Every folder and file has Agent access: Available, Redacted or Not available. It is inherited down the tree, a subfolder or file can set its own, and it covers mounted Google Drive, OneDrive and SharePoint folders. Nothing is ever written to the provider.
- Every call an agent is behind now passes one read gate on its way back. That includes the engine reading context as the person, a setup-grant call rerun as the person, outside API actors, the agent's computer, the MCP door and the email and form helpers. A file in a Redacted folder reads with the literal [REDACTED] where a part is hidden and highlights as ==marks==. Comments never reach an agent. A Not available file is refused, and so is a Redacted file nobody has reviewed: that refusal asks a person ("Redact before I can read"), and Done wakes the agent.
- The gate also covers previews and page pictures, sheets, diffs and changesets, the viewer's data, names and paths in every list, search hits, memory notes, git diffs of a folder with anything hidden below it, connector calls that reach a mounted provider file, and blob-route preview images. A CLI engine is no longer handed a disk folder with anything hidden below it, and the agent computer's mirror drops a file the gate refuses. Search and memory index what an agent may read, so a redacted word cannot be found. An agent may not copy, move or send a file out of its folder's layer.
- A new version carries redactions over. Any it cannot place sends the file back to Needs review, and agents wait until a person places or drops them.
- Find things to redact runs pattern checks on the server, with no AI: names from Records, SSNs, dates of birth, account and case numbers, phones, emails and addresses, plus the file's own name.
- An agent may add a redaction but never take one off or mark a file reviewed. Every redaction, un-redaction, review and agent read is on the file's activity.
- Redaction for AI in Files. A folder's header has an Agent access control. Its popover shows Available, Redacted and Not available, where the setting comes from, and what is set differently inside, each with Reset. Lines carry Reviewed, Needs review, Not available to AI and "Intake is waiting" badges, and a folder line reads "3 files need review" with Review next.
- In the shared viewer, selecting text offers Highlight, Redact, Comment and Ask. Redactions show to people as a fine hatch with a dashed underline, highlights as an accent tint, and comments as a dotted underline. A hover card names who and when, with Un-redact or Remove highlight, Comment and Activity. Scans and pictures take Redact an area. A PDF now reads as its words, so it can be redacted like a document.
- The viewer has Redact and Activity tabs. Redact holds the review state with Mark reviewed or Done, Preview as agent, Find things to redact, what is hidden, what a new version could not place, the name agents see and the file's access. Activity lists who redacted what and when and every agent read, with the (Agent) credit. A chat shows the agent's "Redact before I can read" card, with Open to review and Not now.
