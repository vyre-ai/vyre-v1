- AI tools can use the internet. Claude Code, Codex and Grok reach any public website or service by default: web pages, git clone over HTTPS and SSH, npm, pip, cargo, go and Homebrew work with no setup. Private, local and metadata addresses, the computer's own network and Vyre's own ports stay blocked.
- Console, AI, Internet access: owners and admins choose what AI tools can reach on the internet (Anything public, Only the AI providers, or a list). The choice applies from the next engine start on the Space's servers and on members' computers; refusals are in the audit log.
- A failed turn's Details and Console review sampling show the hosts the engine reached and what was blocked.
- AI tools work in the folders you added to Vyre. On your own computer (your Personal Space, or a Space your computer hosts) Claude Code, Codex and Grok read and write every folder you added from it, read your ~/.gitconfig and known hosts, and push over SSH through your ssh-agent without ever reading your keys. Vyre's data folder, private keys, credential stores and browser profiles stay closed, even inside an added folder.
- AI tools can install what they need. npm install -g, pip install --user, cargo, go and brew install land in your own install locations and are there the next turn. A command that needs sudo tells the agent to hand it to you in the Terminal card. On a Space server, installs go into the Space's own toolbox and persist across turns, never onto the server itself.
