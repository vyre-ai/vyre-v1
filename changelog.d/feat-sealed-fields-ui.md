Sealing is in Records. Add field now offers Sealed. A text, email, phone, number or link field has Seal this field, which asks once, says it is one way, and then moves its values into the Vault. Check for sensitive data lists the fields that look like ID, card or bank numbers or health data, with Seal and Mark restricted beside each (health data can only be marked). On a record, a sealed field shows dots with Reveal; the value appears for ten seconds with Copy and Hide, and the page says the reveal was logged. Replace and Set value send the new text to the Vault, and the page keeps only a reference.
