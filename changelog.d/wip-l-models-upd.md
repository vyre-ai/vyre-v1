## What's new
- When Vyre updates itself and a reply is still running on your computer, the Updating screen now says which chat it is waiting for and counts down the time left. The wait has a cap: when it runs out Vyre ends that reply cleanly and updates on its own.
- A new "Stop and update now" button ends the running reply cleanly and installs straight away.

## What's fixed
- The update no longer waits for a chat forever, and no longer gives up and leaves the update for the next start when a reply is still running at the end of the wait.
