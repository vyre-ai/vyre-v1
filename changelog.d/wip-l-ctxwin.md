- Context windows are the real ones: a model's window comes from the provider's own list (OpenRouter context_length, Anthropic max_input_tokens, Gemini inputTokenLimit, vLLM max_model_len) or from the engine's turn report (Claude Code modelUsage.contextWindow, Codex model_context_window), kept per provider and model. Only when nothing is reported does an updated table apply (current Claude, GPT-6, Grok, Gemini, DeepSeek and GLM are 1M or 500k, not 200k). An Auto pick is sized by the model that ran. The meter, rollover and compaction use the resolved window, and the model list row carries it as contextTokens.
