Agents now start with a real AGENT.md, written as instructions to the agent: who it serves, its operating principles, how to decide, a map of where to do each common job in Vyre, what to save to memory, how to report back, safety rules, and what to do when it is wrong. Your private assistant gets one written for a chief of staff, under its own name ("Irfad’s Assistant"). It acts without asking on reversible work inside Vyre. It asks once, with the draft ready, before anything leaves Vyre, costs money or cannot be undone. Every new agent gets the same skeleton, with "Your job" written from its role line. Each file ends with a Learned section that the agent keeps itself: when you correct it, it adds one dated line, and that change applies at once. A change to any other part of the file still goes to review. Agents whose AGENT.md is still the untouched old starter get the new text as a new version at start; a file anyone edited is never touched.
