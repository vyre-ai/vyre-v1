Add a server from Settings, Computers, in a Personal Space as well as a Team one. Name it, paste one command on the machine, compare the fingerprint it prints, approve. The list shows this computer and your servers with an online dot and what runs on each; Remove ends a server's access at once. Agent computers no longer need a Team Space: they run on a server you added, or on this computer when it has Docker. Until one of those exists nothing about agent computers is shown, with no "Needs a Team Space" messages for them. Every private chat header has a quiet "runs on" chip: this computer, the Space (in a Team Space) or one of your servers by its name; a server that is off is grey with the reason on hover, a chat pinned to one never moves to another machine, and your chats never run on a teammate's. In a Team Space the Space menu has "Chats run on: This computer or The Space" for new chats.
