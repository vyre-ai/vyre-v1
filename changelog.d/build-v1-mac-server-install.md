- Install Vyre Server on a Mac with one command (`curl -fsSL https://vyre.run/install-mac.sh | sh`, attached to every release as `install-mac.sh`). Same signed release check, `--domain` and `--relay`, and folder layout as the Linux installer; a launchd agent starts it at login and another updates it daily at 04:00. It needs FileVault, Docker Desktop or OrbStack, and Homebrew's OpenSSL 3, and refuses without them. Tested on Linux and on a hosted macOS runner (the `installer-macos` job in `desktop.yml`).
- `vyre-server` and the Linux installer now run on macOS too: the encrypted-disk rule reads `diskutil` there, and the digest check falls back to `shasum`.
