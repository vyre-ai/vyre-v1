## What's new
- The install card now has the Assistant's face, a filled card, and Install, Edit and Don't install buttons on one line. A server that needs a key you have not saved shows "Add it" on the Vault line; Install stays off until the key is in your Vault, then turns on by itself.
- A remote MCP server no longer shows a key picker. Its Vault line says the sign-in comes after you install it.
- "Pinned to" shows the version next to the commit. An update shows the versions in its title and a "New access" line when it reaches somewhere new.
- Skills in the chat's right pane show the version next to the name, "Update ready" when a newer one exists, and bordered Share and History buttons on every skill, including ones shared with you.
- Console > Skills > Installed from links shows an icon, the kind, who installed it and for whom, the commit and version, and See changes only on rows with an update.

## What's fixed
- A member adding their own skill no longer fails a permission check. A new skill is registered with its owner when it is created, so its owner can share it with no extra step.
