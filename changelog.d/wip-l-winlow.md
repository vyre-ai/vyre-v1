- Claude Code, Codex and Grok work in a Windows Personal Space with nothing to set up. The engine runs at Low integrity in a Job Object, built by Vyre with the compiler Windows ships, so no admin is needed. It can change only its work folder, its own home, config and temp, and the folders you added. It can read the computer as Claude Code does. Its network goes through the egress proxy. When a turn ends, everything it started ends too.
- Vyre's own files are labelled so the engine cannot read them: the admin token, the seal and Vault keys, the databases and the logs. Settings > Computers says under This computer: "Personal: the AI can read this computer like Claude Code does; it can only change your added folders."
