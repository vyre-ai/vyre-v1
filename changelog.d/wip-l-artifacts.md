## What's new

- An artifact an agent publishes shows in the chat as a real card: a small picture, its name, one quiet line ("Page · Private to you · updated 3:53"), and Open, Copy link and a "..." menu with Share, Open in browser and Delete. The whole card opens it.
- An artifact opens in its own tab inside Chats, named for the artifact, with one header row (back, name, Share, "...") and the page filling the rest. It shows a loading state and, when the page cannot load, a real error with Open in browser and Try again.
- Artifacts open from the sidebar's Artifacts row, inside Chats. It is a grid of the same cards with a quiet search and a Mine, Shared with me, All menu, newest update first, and an empty state with an example ask. Old links to the Apps artifact page land there.
- An artifact now keeps a small picture taken at publish (the agent can pass `thumb`), the chat that made it, and who it is shared with. sites.get and sites.list return them, and the card and the grid show them. The grid's "From <chat>" links back to the chat.
- Vyre for Chrome keeps a picture of an artifact for its card: when the extension opens an artifact in a tab it takes the visible tab once, a second after the page loads, scales it to 480 px wide webp under 60 KB with password and card fields blacked out first, and sends it with the new artifact.thumb bridge op (sites.artifact_thumb_set). The Space keeps it only when there is none yet or the artifact changed.
- The picture is also taken when the person opens an artifact themselves by the plain link: any tab that finishes loading a page on a signed-in Space's artifact host (<name>-a.vyre.run, a.<address> or a.localhost) is captured the same way, at most once every half minute per artifact.
- In the Mac and Windows app the artifact tab shows the page as a native page over the tab (an iframe of the artifact host never kept its cookie there). It steps aside while a menu, the Share sheet or the delete question is open. A browser keeps the frame.
- Agents get better faces. A new library of drawn faces (Faces, Friends, Blobs, Glass) plus Emoji and Upload, 24 curated per family, drawn in the app with the DiceBear collections (public-domain art; never from a service). Faces show how the agent is doing: focused while it works, a smile when it finished, closed eyes when it sleeps, and a blink on hover (not under reduced motion). One "Choose a face" sheet opens from the agent's page and from New agent; the change has Undo. A new agent is offered a face nobody in the Space wears. Agents keep the face they have until someone changes it. People keep their marbles or photo.
- The Vyre for Chrome side panel shows the same agent faces (from its own copy of the library; nothing the app sends is drawn as markup).
