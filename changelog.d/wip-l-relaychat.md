- Fixed a chat on the second computer of a Personal Space sometimes never getting an answer. With both computers' daemons in one process (the two-computer tests), the first computer's periodic job could build the turn engine on its own database; once that computer stopped, the engine on the second read a closed database and every message failed with "database is not open". The engine, and the store that keeps MCP sign-ins, are now set up only by the daemon they belong to.
- The two-questions chat test no longer fails under load. Memory's background learning pass goes through the same scripted model as the chat, and when it ran between the first answer and the next chat turn it was counted as that turn, so the second question was never asked. The test now counts only the chat's turns.
- The scripted model in the live tests now answers memory's background learning pass itself, so a test sees only its chat's turns. A test that checks what memory learns can ask to see the learning pass with an option. The three tests that each handled this on their own now rely on the shared helper.
