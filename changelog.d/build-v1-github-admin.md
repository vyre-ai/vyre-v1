- An admin can turn GitHub sign-in on from the app: Console, Policies, Sign-in requirements, GitHub app. They paste the OAuth app's Client ID and Client secret (`members.sign_in_github.set`); the secret is filed in the Vault as a Space item and is never shown again, only "set". The page shows the exact callback address to register at GitHub with a Copy button and a "Create the GitHub app" link. The server environment (`VYRE_GH_OAUTH_CLIENT_ID` and `_SECRET`) still wins when set; otherwise the saved app is used, with no restart.
