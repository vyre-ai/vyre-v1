A new Space starts with neutral record types only (Contacts, Companies, Projects, Tasks, Meetings, Note boards, plus the system types). The example Kit types (Client plans, Commissions, Leads, Matters) arrive only when the person installs that Kit. At start, Spaces made by an older build lose those example types when they were never used (no records, no edits, no layout or view); a type with any record or change is kept. The removal goes through the schema module's own type drop and is logged as records.types_pruned.
