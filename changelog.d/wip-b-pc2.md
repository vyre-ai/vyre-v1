- You can now type into an agent's terminal yourself: open the terminal from the agent's Computer tab, press Take over, and what you type goes to the terminal. Everyone watching sees who is typing and cannot type, the agent's own commands are refused until you hand the keyboard back (or 15 quiet minutes pass), and everything you type is on the audit log as yours, never as the agent's. The Space server's setting VYRE_TERMINAL_TAKEOVER=0 turns it off.
- Keys you type are sent once: when a connection drops and the app tries again, the terminal never runs a command twice, a late retry never lands in what the agent runs after you gave the keyboard back, and a batch that went missing is refused in plain words instead of being skipped.
- When keys you type do not arrive (your take-over ended, someone else has the keyboard, the connection failed), the terminal's bar now says so in one plain line, and it goes away when keys arrive again.
- What you type into a terminal, and the screen it answered with, are no longer kept in the server's records of past calls; a pasted secret stays out of them.
- When a manager takes the keyboard of your agent's terminal, or hands it back, your chat with that agent gets one quiet line saying so. A terminal one person opened for themselves can no longer be typed into, taken, read or closed by anyone else, managers included. If the person holding the keyboard is suspended, removed or signed out, the keyboard goes back to the agent at once. A paste that is far too big is refused with a plain line, and a terminal left in tmux's scroll mode still receives what you type.
- A command can no longer be run into another person's own terminal by its id, their last line and last command are not shown to anyone else, and a member can no longer rename an agent's terminal. A manager can close a terminal whose opener has left or been suspended, and a person's own terminals are closed when they are removed or suspended.
- You are told when someone takes your agent's keyboard even if you have no chat with it yet (a chat is made), the names in that line are quoted and cut so they cannot read as instructions, and keys sent again under the same number with different text are refused instead of silently dropped.
