A list can be sorted and filtered by a formula, lookup or rollup field. A person it is hidden from, or who does not see every record it reads, gets the default order and no filter on it. A file exported from a table has the computed values the person may read, and a filter or sort on a field they cannot read leaves a row out instead of picking it.
Sorting by a computed field reads each record's value one by one (a scan, no index). A page of records reads all its computed values and the rows they came from in a few queries, not two or three for each record.
A page cursor of a list sorted by a computed field carries the last value of that field in it, so it is not opaque to someone who may read that field; a person it is hidden from is never given such a cursor (their sort by it is dropped).
