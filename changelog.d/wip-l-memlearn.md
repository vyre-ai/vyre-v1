- Memory learns after every reply. Once a turn finishes, Vyre reads what you said since its last look and decides, for each thing worth keeping, whether to add it, update something it knew (the old fact closes with an end date and stays in its history), mark something no longer true, or leave it. Every fact links to the chat line it came from. This runs in the background and never delays a reply: in tests the turn completed in about 5 ms with the learning pass still held open.
- Learning is paid by the account that ran your turn, on the cheapest model it offers: Haiku through Claude Code on a Claude subscription, the smallest model on the Codex list, and the lowest price in the catalog for OpenCode Go, OpenRouter and API keys. Free OpenRouter models are never used for it. Someone else's account never pays for your memory, and the Space AI key pays only when your turn itself ran on it. There is nothing to set up.
- Each person has a daily learning quota: 150 model passes and 400k input tokens by default, whichever comes first, reset at their local midnight (Settings > Profile > Time zone). A pass sets its tokens aside before it starts and runs only when they fit, so the quota is never crossed. Past the quota, Vyre keeps simple notes by rules for free until midnight, with no error. Owners and admins change the limits in Console > AI > Memory learning; you see today's use in Settings > AI > Memory and privacy.
- When a provider says to slow down (a rate or usage limit), learning pauses on that account, one minute doubling up to six hours, and uses the free rules meanwhile. It never shows in the chat.
- In a chat with other people, Vyre learns only what you said about yourself, into your own private memory. Other people's lines are never read for your memory, and the chat a fact was heard in travels with it.
- A chat can be set not to be remembered (memory.chat_learning.set, or the thread setting memory.off). While it is, nothing is learned from the chat, after a reply or when it goes quiet. Anyone in the chat can turn it on. The person who turned it on, or who started the chat, can turn it off.
- When a chat goes quiet, capture by rules now skips the lines a turn pass already read.
