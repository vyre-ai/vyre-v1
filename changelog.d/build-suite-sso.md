- A firm can sign its people in with its own Google or Microsoft sign-in app (OpenID Connect). The Space starts the sign-in with PKCE and a nonce, exchanges the code with the secret held in the Vault, checks the ID token's signature, issuer, audience, expiry, nonce and that the address is at the firm's domain, and then hands the page a one-use ticket that identity.sso_sign_in spends. Only people already in the Space (or holding an accepted invite) are signed in; a provider with no firm domain set signs nobody in.
