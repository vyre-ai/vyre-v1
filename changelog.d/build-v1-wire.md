- Memory is live in chats: an agent's MAP.md and memory rules go into its system prompt as stable blocks, each message is matched against memory as the person who wrote it and the recalled facts reach the model with their source (API-key chats and CLI engines), a closed or idle chat is captured by the agent's captureMode (off keeps nothing, propose leaves every fact to accept, auto_low_risk merges the low-risk kinds), and memory.maintain runs about once a night.
- Files > Knowledge has Proposed and Graph rows that open the Memory proposed and Memory graph screens; accepting or rejecting a fact there changes what agents recall.
