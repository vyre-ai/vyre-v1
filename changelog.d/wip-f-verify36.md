- When an agent writes to a teammate as itself, the note the teammate types when they send a request back no longer shows up in the chat of the person who asked; only the outcome does.
- A chat named from your own words no longer ends on a dangling word ("Create a", "Draft the October note for"); with too little to name it, it waits for a fuller request.
- When a chat cannot be read by the engine, the log now says so ("thread_unreadable") instead of claiming the chat has no agents.
- Inside an agent computer, Vyre for Chrome is reported as asleep when its worker is idle, and as missing only when it is not installed (it used to read "workers: 0" while fine).
- A tab now always shows the current name of its chat: a chat named or renamed while you are on another tab changes on its tab, and a restored tab shows the current name; the two ways a chat can be opened share one tab.
- When the server cannot refresh who may see what for a moment (a busy server), a chat you just made no longer stays "not found" for you: the refresh is retried every half second until it works.
- The recovery code now says what it is, that it is shown once and where to keep it; the claim page fingerprint says what to compare it with; the forgot-password form says the saved code keeps working.
- First-run setup: steps with nothing behind them (Agents and computers, Shared data, First team win, and a member's Personal Space) are no longer shown; the people step says plainly when no company directory is connected instead of "Could not read this right now"; the end screen says "You can start now" and how many steps are still open; setup no longer sends you to "the Console" without saying what you will do there.
- A Space with no name of its own is called "your Space" everywhere, never by its raw id or its web address; its tile shows the Vyre letter; Console, Space, General shows an empty name field to fill in, and first-run setup no longer pre-fills the name with the address.
- Adding an AI key now checks it with the provider first: a key the provider refuses says so in the provider's words and is not saved, an unreachable provider says the key could not be checked, and only a key that works is called connected.
- Invite links have a Copy button; typing "sign out" in the search finds Sign out; the built-in skills list no longer shows the internal "focus" skills; a greeting in front of a request no longer names the chat.
- Removed the "Trust this device" switch from the join steps: nothing used it.
