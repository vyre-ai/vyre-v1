- Typing `#` in a chat lists the person's connected sources first: their Google Drive (My Drive and shared drives), OneDrive, SharePoint sites and libraries, Dropbox, GitHub repositories and live folders, each with its provider's mark. Before, Folders sat below recent records and files, under the fold of the menu, and showed four rows at most. Now Folders leads whenever it holds a connected source, and every source shows.
- Picking a connected source or any folder in a chat links it into the message as `#Name` with its folder id. The agent sees `[Linked: My Drive (folder fld_...)]`, and the link's chip opens the folder in Files. Before, a folder pick set a folder chip that the chat never sent, so the pick was lost.
- Links picked with `#` or `[[` are sent with the lower-case kind (`file`, `folder`, `record`) that opens them beside the chat and draws a mounted file's source chip. Before, the menu's "File" and "Folder" did neither.
- Typing a provider's name finds its sources: "google" finds My Drive, "sharepoint" finds a library called Documents, "repo" finds a GitHub repository. A folder found by name inside a source carries that source's mark, and a git folder says it is a repository.
- Someone who has not opened Files yet still gets the company Drive. The first `#` of a session asks for it (`mounts.company_drive`) before it reads the mounts.
- When the connected folders cannot be read, `#` still shows everything else, with a quiet line saying the connected folders could not be read. Before, it showed nothing about them.
