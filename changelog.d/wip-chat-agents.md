- Tag two agents in one message ("@Dex @Nova") and each answers on its own. Before, the chat's lead could also answer the other agent's reply, so one tag could set off an extra turn.
- A chat can now ask who is on a message that asked more than one agent: each agent working, waiting on another, replied or stopped (a new read, engine.round.get). It reads the engine's own queue, so nothing stays stuck after a restart. The row under a message in the chat will draw from it.
- Tag two or more agents, or say "both of you", and a slim row under your message shows each agent and what it is doing within a second ("Dex  Working", "Nova  Working"), so no tagged agent looks ignored. It reads once when the message appears and again when the chat's live stream reports a turn start or end, with no timer. The row folds away when every agent has replied.
- After a message asked several agents and each answered, "Go with Nova" leaves one quiet line in the chat, "Decided: going with Nova's answer" (a new write, chat.round.decide). No agent is woken by it.
- When a message asked several agents and each has answered, one card under the last answer shows a tab per agent with that agent's answer, a "Go with <name>" button and "Let them discuss". It folds away by itself once you write anything.
- "Let them discuss" on the round table opens the thread under your message and has the agents that answered take a short turn each, ending on one line that starts "Decided:" (a new write, chat.round.discuss). At most four turns. The chat gets one line, "Dex and Nova are talking it over", that opens the thread.
- Agents asked together are told to open with one "Answer: ..." line. The round table shows "2 of 3 agree" or "All agree" only when those headlines are the same after trimming case and punctuation, otherwise it shows the headlines side by side and claims nothing.
- Going with an agent's answer and letting agents discuss are a person's press only (no agent can call them). Going with an answer twice leaves one line (the other agent's answer replaces it, and a round you have written past cannot be decided); a second "Let them discuss" opens the thread and starts no more turns. The round row no longer tells another member that your private Assistant is working.
- When agents discuss, the line in the chat "Dex and Nova are talking it over" becomes the outcome: "Decided: ..." when an agent ends on a Decided line, or "They did not settle it" when the talk ends without one. Pressing it still opens the thread.
- When agents decide in a discussion, the line says "Agents decided: ..." and not "Decided", which is only for your own press. The line changes on every open client at once, without a reload. A discussion that used its four turns says so: "They used their 4 turns without settling it. Ask again to go on."
