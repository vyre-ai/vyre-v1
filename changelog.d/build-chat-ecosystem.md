- Skills in three tiers. An agent sees an index of SKILL.md skills each turn (Vyre built-in, the Space library an admin keeps, the agent's own skills/ folder and what a plugin brought) and opens one with `load_skill`. New Console page Skills to paste or upload a skill, switch it off or remove it.
- Plugins. An admin adds a Claude Code marketplace (an https git address or a folder), browses it, allows it and installs a plugin into the Space or into one agent. Its skills become Vyre skills, its commands become `/plugin:command` commands, its sub-agents become agents you can start from, its MCP servers become tools for every model and its hooks run in the sandbox. Plugin code never runs in the daemon: it runs in the same Seatbelt or bubblewrap sandbox as a CLI engine, in the person's work folder. A secret option is a Vault handle, filled at the last moment and removed from every result. New Console page Plugins and tools; any MCP server can also be connected by address or command.
- Outside tools go through the Gate: a tool the server says only reads runs at once, any other call by an agent waits for the person's approval.
- A chat turn held at the Gate now goes on when the person approves, with the call's answer, or is told it was turned down. Before, the turn waited for ever.
- A Kit can bring skills, a marketplace, a plugin, an outside tool server and an agent as shorthand items next to its record types; the install sheet names each and one click installs them all.
- The Mac sandbox opens the root directory entry, which macOS 26 needs to start any program.
