- When you ask an assistant to connect Stripe, Resend, HubSpot, Mailgun, Dropbox Sign, Zoom or Twilio, you now get the same connect card as for Fathom. Paste the key (Zoom and Twilio ask for several values), see the exact address it will be sent to, and press Connect. The key is tried once against the service itself and is kept only when it works. A wrong key, a key that works but cannot read what the check needs, and a service that cannot be reached each say so in their own words, and nothing is kept. Mailgun asks for the region first and sends the key to that region's address alone.
- An action's answer never carries a secret any more: any value under a key such as auth_token, client_secret, api_key or password is replaced by *** before it reaches the assistant, an Automation or a test. A value that is "..", or holds a slash, ? or # is refused where it would sit in a web address. A built-in service a Space has not changed is brought up to date with the product; one it changed is left alone.
