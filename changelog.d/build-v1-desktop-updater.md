- The desktop app updates itself. Settings, This computer, Update Vyre checks the app's release channel (a release candidate reads beta, a release reads stable), says what it found, and installs only when the person chooses; the app checks the signature before it installs and restarts.
- The update bundles (the Mac `Vyre.app.tar.gz`, the Windows `VyreSetup.exe`) are signed with the Vyre release key, the one the servers already trust, so the desktop adds no new secret. The build writes only a BLAKE2b-512 digest line beside each bundle; the isolated sign job turns the digests into minisign signatures and writes `desktop-<channel>.json` in Tauri's feed format; publish attaches the bundles after checking them against the signed digests. The key pinned in `tauri.conf.json` is derived from the compiled-in release key, and a test fails if the two drift.
