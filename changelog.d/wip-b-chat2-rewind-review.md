- Rewind never stores a secret: a point leaves out files named like credentials, tokens, keys, service accounts and keystores, and files holding a private key or a vendor token whatever they are called. The store is private to the server (mode 700, files 600). Going back never removes or writes such files.
- Going back checks everything on the server: the point and the message must be yours, the range of messages folded is worked out from that message (you cannot choose it), and it is refused while the agent is working ("Stop Dex first, then go back"). A path that could not be put back is counted and named. A point finished after the agent had started is called "during", never "before". A turn on your own computer, or in a crew, task or helper thread, takes no point.
- An Undo is recorded and can itself be gone back to; a rewind that a restart cut short stays on the chat with Undo. Points older than 14 days go in every chat, touched or not, in one hourly sweep; an agent in Trash keeps its points.
