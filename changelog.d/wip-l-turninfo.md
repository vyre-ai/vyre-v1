- Chats: every agent reply now keeps how it was made. The turn record holds the model and effort, the AI account it ran on (a sign-in, the person's key or a Space key), where it ran, when it was queued, its first word and its end, and the tokens in and out. It also holds cache reads, cache writes and reasoning tokens when the provider reports them, each tool call with its duration and whether it was held for a yes, and any account switch.
- Chats: a reply's cost is now real. A sign-in turn is included in the plan. An API key turn uses the provider's own price when it sends one (Claude Code, OpenRouter), and otherwise the list price of the day it ran. A model without a listed price says its cost was not reported instead of showing $0.
- Chats: chat.reply_details answers everything about one reply for its hover card and Details tab, including what the agent knew. In a shared chat only the asker and the people who manage AI spend see the account, the cost and the tool arguments.
- Engine: engine.turn.get no longer answers for a chat the caller cannot open. It now shows the tool steps and account switches of chat turns too.
