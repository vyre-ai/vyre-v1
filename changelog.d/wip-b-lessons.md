- Lessons are no longer printed under every reply. A reply that used lessons has one quiet mark on its top row, next to the time, with a number when it used more than one. Pressing the mark opens a small list where you pressed: each lesson on one line (press the words to read all of it), with See and Remove. Escape closes it.
- The line under a message that taught something now says only "Learned a lesson", with Undo and See, and none of the lesson's words. Once the agent has answered, it folds into the same quiet mark on that message.
- The mark says "Kept in mind", because a lesson put in front of the agent is kept in mind, not always used. It shows only on the reply to the message the lessons were sent with (the first of the chat). Before, every later reply in a chat showed the lessons of the first one.
- Every lesson that fits is now sent to the agent when a chat starts, newest first, up to 250 of the 350 tokens (before, only the newest three). Knows says for each lesson whether it is sent, or not sent for lack of room.
- A lesson from a message with two lines now keeps both as two sentences ("Show me your draft text here first. And you are not my automation agent."). Before, the line break was lost and the two ran together.
- A reply's Details have a "Lessons kept in mind" section with one line for each lesson.
- A reply that continues after a helper finishes now starts a new paragraph. Before, two answers could run together with no space ("kernel.The terminal").
- An agent that writes the name of a tool the way it sees it (a name beginning mcp__) now reads in plain words to you.
- The name of a tool the way the model sees it (mcp__...) no longer shows for a moment while a reply is being written: it reads in plain words from the first frame.
