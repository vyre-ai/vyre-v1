A Markdown table is a table of cells in Edit: Tab goes across, Enter goes down, a cell's menu adds and removes rows and columns, a block of cells pastes in, and an untouched table is written back exactly as it was. Wide tables use the width of the pane while text keeps its reading width, with the first column and the header row staying in view. A file dragged out of a connected folder, or into one, asks first (Move it, Keep a copy there, Cancel).
