- Agents now learn from every correction. When you edit an agent's draft, say no, undo or decline what it did, or ask for it another way, the agent keeps a short lesson, and its next chats open with that lesson in front of it. A lesson is a memory fact of kind lesson that only you can read, kept by that agent, shown in the Learned feed with Undo, and counted each time an answer uses it. Settings, Memory has a switch, "Learn from my corrections"; off, nothing is kept.
- A lesson from a chat other people read can only use words that chat already shows, and a lesson never reaches a shared chat. Sharing one goes through the existing promotion, so a person accepts it first.
- A new capability, memory.corrections.record, keeps a lesson for a correction made outside the chat's words. Declining or sending back an agent's held action (gate.deny) and editing an agent's email draft now call it as the person. A new capability, agents.instruction.append, adds a lesson to the agent's AGENT.md as one line under "Lessons from corrections", as a new version with Undo.
- In the app, the message that taught a lesson now has a quiet line under it, "Learned: the lesson, Only you, Undo, See", and the reply that used a lesson says "Used a lesson" outside the folded work. The Knows tab lists the lessons the agent kept, each with how it was caught, when, how often it was used and who may read it, with Edit, Where it came from, Share with the Space, Make it an instruction and Forget, under the switch "Learn from my corrections". Settings, Memory and privacy lists every lesson across agents with the same switch.
- Facts an agent learned after a turn now show their Learned line under the message they came from (the line their link names), not only facts remembered from one message.
- A lesson is never part of the profile: About you does not list it and it cannot be moved onto a public or private profile.
- The screenshot script can shoot the desktop size at another width and height with SHOTS_DESKTOP_WIDTH and SHOTS_DESKTOP_HEIGHT; unset, it is 1280 by 800 as before.
