Describe a Flow in a chat and it shows up there as a card. When an agent drafts an Automation from a chat, the thread gets a card from the server with the Flow's name, what it does in plain words ("When a record changes. Then make a task to call the lead. Then email me the summary, held for your yes") and two buttons, Turn on and Test, that run as you; an agent cannot forge the buttons, because only the server writes a card whose buttons call something and the words are built from the draft itself. Also fixed: Flows that start from an event (a record changes, an email arrives, a form is submitted) never started on a running server; they do now. A Flow that makes the very record it listens for runs once, two Flows that trigger each other stop at the chain depth, and a bulk import cannot start thousands of Runs: past 100 starts in a minute the Flow pauses and its owner gets a Needs you note saying so.
