- Compact is real: the Compact button and /compact call engine.compact. Claude Code compacts its own session with what you ask it to keep; for Codex, Grok and API models Vyre writes a summary that starts with those words and the next turn starts from it. The chat shows one line with the context left, and the meter shows the same.
- Keep this every time is saved per chat. Every compaction of the chat keeps those words: yours, an API model's automatic one, and the CLIs' own through the compact instructions in the chat's CLAUDE.md and AGENTS.md. The panel opens with them ticked.
- Claude Code, Codex and Grok sessions survive a restart: Vyre keeps each engine's own session id per chat and resumes it after a restart or when a warm session was closed. When the engine no longer has the session, the turn starts a new one from the chat's summary and recent messages and says so in one line.
- On Linux the engine's home is the person's scratch home for every turn, as on a Mac, so the sessions a CLI keeps on disk are there for the next turn. Sign-in files placed there are still removed when the process ends.
- The about-vyre skill says what is now true: Compact keeps what you name on every engine, and a restart resumes the engine's own session.
