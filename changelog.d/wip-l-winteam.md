- Team Space turns run on a member's Windows computer, in Vyre's own WSL2 Linux under bubblewrap, as the owner ruled (RULINGS 15): the same files and network wall as a Linux server, with the Space's internet rule sent to it at each turn's start. A Personal Space on Windows keeps Low integrity (RULINGS 14). No setting chooses this; the kind of Space does.
- Without WSL, a Windows computer offers no engine to a Team Space, so Automatic runs those turns on the Space's server. Settings > Computers shows "Set up the Windows sandbox for team chats" once, while WSL is off. It turns WSL on with one click after Windows asks for administrator consent, and a restart finishes it.
- Console > Internet access says how the choice holds on Windows: sealed for team chats, and a guide through Vyre's proxy in a Personal Space, where a program can still reach the internet directly.
