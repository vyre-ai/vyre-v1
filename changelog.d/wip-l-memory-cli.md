- Memory learning for members whose chats run on their own computer through a CLI subscription (Claude Code, Codex, Grok): the learning pass now runs its one request on that computer, through its link, never on the Space's server. It takes no placement decision, does not wait for or hold the turn gate, and is given up after 90 seconds. A computer that is off, on a link that is not private, without the engine, or someone else's only skips the pass: the rules still learn, nothing is paused, and the next turn tries again. The same write rules apply as for a key on the server: for-me-only notes stay in the person's layer, and what a one-person channel or private chat learned before it gained people stays with its starter.
