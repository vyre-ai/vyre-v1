- Links: one resolver, reach(item, viewer), decides where a link, chip, row, menu item or search result goes, so nobody is sent to a place they cannot open. It returns the deepest place the viewer can open, else a read-only peek, else plain text with no link styling; hover and press read the same answer.
- Machines: the "on <machine>" label of an agent's computer goes to Console, Computers for an admin, to Settings, This device for the machine's owner, and to a peek (name, Online or Offline, the agents there, "Shared server" or "Maya's computer") for anyone else. A machine that needs an admin offers Tell an admin, which sends the Space's admins a request and shows one quiet line.
- Vault, Records and Settings: the Backups, Outside actors, Schema and Connect your company doors are shown only to a person who can open that Console page, and Cmd-K no longer lists a result whose place is not on the person's rail.
- Links: every click that opens something goes through one door, ShellRuntime.open, which asks reach first. A Console page opens only for a person whose console.nav lists it, and a chat, task, record, file, run, agent, project, goal, automation, folder or agent computer opens only when the read its page makes is not refused; a refused click does nothing and says "You do not have access to that". An item opened once opens at once the next time.
