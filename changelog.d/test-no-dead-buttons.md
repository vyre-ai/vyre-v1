- Tests: a no-dead-buttons gate. scripts/click/dead-buttons.mjs opens the real app on WebKit under the desktop app's real CSP, in a Personal and a team Space, clicks every button, menu item and link on every place and every state a click opens, and fails when a click changes nothing a person can see within 1.5 s. There is no allowlist: any dead click fails the gate. A new lint, scripts/lint/no-silent-calls.ts, fails a fire-and-forget capability call in apps/app or ui that has no error handler (known list in scripts/lint/no-silent-calls-known.json).
