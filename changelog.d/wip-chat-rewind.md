- The files half of Rewind: a checkpoint of an agent's work folder in a store the agent cannot reach, going back to one (which first takes a checkpoint of now, so it can itself be undone), listing them. Nothing in the app calls it yet.
- Every turn of an agent that works in a folder on the Space's computer now leaves a checkpoint of that folder first (for Rewind), in a store the agent cannot reach. It never stops a turn.
- Rewind, the server half: in a private chat with an agent a person can go back to any turn's point. The agent's work folder is put back as it was, the agents stop reading the messages after it (the chat keeps and shows every message), and one line says how many files were put back and that messages stay and anything already sent stays sent. It is off in a chat with other people. Going back first saves a point of now, so it can be undone. The menu, the message bar and /rewind are not wired yet.
- The Rewind card ("Go back to"): each point with its time, what you had asked and how many files, and before anything is pressed what going back undoes and what it never touches. Not reachable from a menu yet.
- Rewind, answers to review: a point is taken as each CLI turn starts and a turn waits at most 100 ms for it; the last 30 points are kept for 14 days with caps per folder and per Space; secret files are never copied; points are erased with their chat, agent or person; going back to the point a rewind took first undoes the rewind and the agents read the later messages again; the card says what is not kept, how long points last and why there may be none. Proven on a real CLI turn on a booted daemon.
- Going back never writes or removes through a link in an agent's work folder: every path is walked one component at a time, a link is never entered, and a link met while removing a folder is removed, not followed. A folder with more than 150,000 files or 8 GB, or one too slow to read, is skipped in the background with a reason and never delays a turn.
- Going back with a git repository inside the agent's work folder no longer stops half way: the project inside is left exactly as it is, and a path that cannot be put back is counted ('N could not be put back') while the rest goes on.
