## What's new

- A manager can set how a project stands (On track, At risk, Off track, On hold or Done) by hand, and the project says who set it. Without one, it is read from the late tasks.
- A project's status update has a draft: Draft again writes it from the project's facts on your own AI account, you can edit it in place, and Post puts it in the project channel as you.
- A project lists the helpers working for it with a live state (Working, Done or Needs you) and what each is on, and Vyre can find the project a channel belongs to.
- A project links to records, files, chats, tasks, artifacts, mail threads, calendar events, pull requests, commits, CI runs and web addresses. Each link shows its state live from the source, such as a pull request Open or Merged, or an invoice Paid or Overdue. Agents that may edit the project can link too.
- Rules link new items by themselves: a repository, a record filter or an email domain. Taking one auto item off the project means it never comes back.
