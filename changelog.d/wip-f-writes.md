- Two writes to the same file at the same moment no longer collide. Before, both could report success, the second one's text won, and History showed two versions with the same number. Now one lands on the version it read and the other is told the file changed, so it reads again and re-applies. Writes with no version still go through, each on its own version number.
- A note now counts its saves, like a task. A save made on an older version is refused with one plain sentence instead of replacing a later change, and a pin and a label made at the same moment both stay.
- An agent's change to a file, record or task is made on the version the agent last saw, without the agent having to send it. If someone else changed the thing since, the agent's change is refused in one plain sentence that tells it to read again and make its change on top, instead of silently replacing the other change. A thing the agent never read is written on the version it had when the agent started working.
- The same holds for an agent's change to a memory page or an automation: it is made on the version the agent last saw, and refused in plain words if someone changed it since.
