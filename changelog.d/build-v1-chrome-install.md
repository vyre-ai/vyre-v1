- Install Vyre for Chrome from the desktop app: Vault, Advanced, Browsers. The app copies the extension into its own folder, writes the native messaging host (a launcher for the bundled Node plus a manifest filled from the extension's template, naming this extension only) into each installed browser's host folder or the Windows registry, and shows the three clicks Chrome needs (Developer mode, Load unpacked with the folder to pick, pin it), with buttons to open Chrome's extensions page and show the folder. There is no Web Store listing yet.
- The extension has a fixed id on every computer (its manifest pins a public key) and carries the release version (`1.0.0-rc.3` is version 1.0.0.3 named 1.0.0-rc.3), in the release zip and in the desktop bundle.
- The native host finds the daemon that hosts a Space (the Mac server, then the Personal Space) before the device daemon, which has none.
