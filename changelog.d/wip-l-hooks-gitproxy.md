- Git proxy: a Claude Code or Codex session now pushes and fetches through the Space (`/git/github/<owner>/<repo>.git/...`) instead of holding a GitHub token. A push to a branch or a tag lands with no question when the person's settings say Always; a push to the default branch, and any delete of it, waits for the person's OK with a card in the chat and progress lines in the git client. A no, or ten minutes without an answer, ends in git's own "remote rejected" and GitHub is never called with a write token. Mixed pushes are all or nothing, the pack is streamed and never held, and a push the proxy cannot read exactly is refused. The session environment carries a proxy token that ends with the process, and no GitHub token under any name.
- Approvals: releasing a held act now needs the releaser to be the hold's current approver (or someone the Space's grants cover for an ordinary act; a person-only act stays strict). When a task's approver slot is assigned, delegated or escalated, the hold follows it and `gate.approver_moved` records who moved it, from whom, to whom and how. The person who held the old slot can no longer release it.
- Approvals: a Space-wide Edit grant no longer lets any member release a hold waiting on a role (it needs Manage on the task), and a moved approver slot is followed only when the mover may decide the hold; task.escalated now carries who escalated it.
