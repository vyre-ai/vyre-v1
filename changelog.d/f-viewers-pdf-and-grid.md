A PDF opens in Files as its real pages, drawn as you scroll (a 500 page file shows its first page in under a second), with zoom, fit width, a page number you can type into, a page strip you can hide, selectable text, Find that marks the matches on the pages, comments pinned to a place on a page, Redact for AI on an area, and Save a redacted copy that makes a new PDF with the marked areas gone from the file. An Excel workbook opens as a grid with every sheet as a tab, number, currency, percent and date formats, the frozen header row and column widths; in Edit you can type into cells, paste a block, add and delete rows and columns, undo and redo, formulas recompute, and each change is saved as a new version of the same file (in a connected Drive or OneDrive folder it goes back as a new revision).
