## What's new
- One Markdown editor for every Markdown body. It edits styled as you type (headings, lists, checklists, quotes, code and links), with a slim formatting bar, a small bubble on a selection, shortcuts shown in each button's tooltip, and Markdown shortcuts such as #, -, [ ], > and three backticks. A Markdown switch shows the plain text in a readable font with colour on the syntax. The bar hides in View and in Markdown mode.
- Files .md, AGENT.md, SKILL.md, the instructions of a new agent, a task's description and working notes, the body of a note, and long-text record fields all use it. The old text boxes are gone.
- What is saved is plain .md that agents read. A file you do not change comes back as it was written: blank lines, list markers, tables, HTML and front matter are kept, and text is escaped only where it would otherwise read as markup.
- Pasting strips the indent the text was copied with and turns pasted Markdown into headings and lists.
- Edits save themselves after a pause as a new version. The file header shows Saved with the version number and Undo. The Review and save row is gone; a Space that asks for a review keeps the edit as a draft with Review in the header.
- The check strip: every chip jumps to its line, and a problems chip opens the list of what to fix. The inherits check now accepts Follows VYRE.md and close variants, not only an Inherits line.
- The file header keeps Saved, the Styled and Markdown switch, View and Edit, Undo and Ask. Find, details and history moved into the ... menu.
- The highlight behind an @mention in the message box now stays on the name in a long draft. It followed the text only until the box started to scroll, then slid onto the wrong words.
