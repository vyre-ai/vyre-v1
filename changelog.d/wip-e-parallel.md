Agents asked together now work together. When you tag two or more agents in one message (or ask everyone), each one starts at once and answers its own part, and the replies appear in the order they finish. Before, the second agent only started after the first one finished. One agent still never works on two things in the same chat at the same time. Stop on one agent's reply stops that agent; Stop everyone stops all of them. A message that tags nobody, sent while several agents work for you, reaches all of them; a message that tags one agent reaches that agent.
