- /btw: type /btw and a question to ask something on the side while an agent works. The running turn is not touched; a small aside under the chat answers on your own account with what the chat knows (summary, recent messages, what the agent is writing now), read-only, and streams. Keep posts the answer as a card, Dismiss puts it away; the agent in the chat never sees it unless you keep it. A message queued behind a running agent has Send now.
- A message queued behind a running agent can be taken back to edit (Edit: it leaves the queue and the chat, its words return to the composer) or sent first (Send now: stop and send, answered once). /btw is listed first in the slash menu.
