- Importing a Claude Code or Codex session now keeps its tool calls: each assistant message carries what its tools did (a line such as "Edit src/app.ts" or "Run npm test"), whether it worked, and the start of what it returned with secrets removed. The preview shows them before you confirm, the archive lists them, and a continued chat gets them as context. Sessions already imported get their tool calls filled in on the next import, once.
- Continue a chat in another Space you are signed in to: the chat menu lists each one ("Continue in Personal") and `/continue <Space>` does the same. A new chat starts there with that Space's assistant, opening with a copy of the conversation by real names; the original chat is not changed.
- Continuing a chat in another Space is allowed only when you are the only person in it (agents are fine). Any chat with another person, or one another person ever wrote in, says "This chat has other people in it, so it can't be copied to another Space." and copies nothing.
- Plugin slash commands show in the chat `/` list (read from `plugins.commands.list`) and run by sending the prompt the plugin renders (`plugins.command.render`) with what you typed after the name.
