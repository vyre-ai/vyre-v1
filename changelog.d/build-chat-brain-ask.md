- Ask Vyre is one door. Files, Vault, Automations and the Files review page all open the person's Ask thread about the object with the agent they picked (the newest one on that object, else a new one), and a link with `with` and `about` is no longer dropped. "Bring this conversation" starts the Ask from a summary of the chat the person was in. A message sent in an Ask pane carries where the person is (the place, the open object, rows and filters), so "this" means the thing on screen.
- API-key chats now apply what they ignored: the agent's allow and deny lists, plan mode, and an Ask pane's level on its object (a view-only person's Ask only reads; `chat.ask_level`). The tool set is read as the asker before it is built.
- A chat can have a reviewer, an agent or a person (`engine.reviewer.set`). After the lead agent's turn the chat shows one quiet line, "Asking <name> to check this.", and the reviewer answers once; a person reviewer gets a Review task. An agent that mentions another agent in a private chat now reaches it.
