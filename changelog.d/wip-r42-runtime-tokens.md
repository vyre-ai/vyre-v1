- Helpers started by one agent now share the same cached start-of-prompt: which thread a helper is (its id, title, scope) moved out of the shared "Where you are" block into its own "This chat" block that follows it, so the provider can read the cached prefix for the second and later helpers instead of paying for it again (modelled five-helper run $0.77 to $0.67; live cache hits not yet measured).
- A helper whose brief is a short mechanical lookup (list, find, extract, copy, count, format) now starts on the faster model of the parent's own account unless the agent named a model or gave a reason; its row shows the pick ("plain lookup, so the faster model") and Change model still overrides it. Anything about evidence, contracts, risk, liability, summaries, judgement, writing, images or documents, and any long brief, keeps the model it would have had (modelled five reading helpers $0.77 to $0.20).
- A command that prints a lot no longer floods the agent: past about 1,500 tokens of output the agent reads the last 40 lines, up to 20 earlier lines that look like a failure with their line numbers, and the counts, and terminal_read reads more. The terminal tab, the people's views and the hooks still hold the whole output (a 100,000 character log: 27,778 tokens to 992 for the agent).
- An agent that reads the same file, record, task, page, mail or event again in one turn and finds it unchanged now gets one short line saying so instead of the same pages again; the call still reaches the server and its access check, a changed answer comes back whole, and nothing is shared with other agents or turns.
