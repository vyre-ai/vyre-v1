Internal: the extension tells the agent's own clicks and keys from the person's by what it sent (kind, place or key code, matched once, one second), not by a clock, so a click elsewhere or a key the agent did not send during typing pauses it. The page sends the extension's own worker only the kind of event, a rounded position and the physical key name (which on a normal layout names the character); the worker keeps nothing of it. A person's key or click that equals one the agent sent within the last second is not told apart from it.
