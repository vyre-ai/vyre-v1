Internal: the extension tells the agent's own clicks and keys from the person's by what it sent (kind, place or key code, matched once, one second), not by a clock, so a click elsewhere or a key the agent did not send during typing pauses it. The page sends the physical key code (on a normal layout it names the character), the event kind and a rounded position to the extension's own worker only; the worker matches it and keeps nothing, and none of it is stored or leaves the extension. A person's key or click that equals one the agent sent within the last second is not told apart from it.
