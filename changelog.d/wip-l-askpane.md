- Ask Vyre opens in a pane on the right of the place you are in, beside the thing you asked about, and no longer takes you to Chats. This covers the Ask buttons on a file, a Vault item and its provider page, an Inbox conversation (the head and the composer), Inbox New message, Records (the sidebar, the Record types page, the new type sheet, Bring in your CRM, Change how it syncs), Automations (the start page, a failed step or run, Ask Vyre about this in Analytics, Build a connector, Set up a saved key), Apps New site, and Add to Automations and Sync to Records from the Vault. A record page and every Settings page now have an Ask button in their head. Cmd-K has "Ask Vyre about this" in every place except Chats.
- The pane is the same in every place: the compact chat with the agent dropdown (your Assistant first), the model picker and the place's focus skill. A chip names the thing; its x makes the Ask about the whole place. New starts a fresh conversation. Open in Chats opens it there as a full chat. Escape closes it. You can drag it wider, and each place remembers its own width. The pane stays open while you move around inside the place.
- One Ask conversation per thing per person: asking again about the same record, file or automation continues it. Every Ask is kept and listed under Ask history on the Threads page in Chats.
- Every message sent from the pane tells the agent what it is about: the thing as the open object, with the place's focus skill and what the button added, such as a failed step and its error code. Before, an Ask from Automations reached Chats as a plain chat that knew nothing about the automation.
- An Ask about a place with no object named (Files, Vault, Inbox, Settings and its pages, Apps, Home) works at the person's own level, as Records and Automations already did. Before, it could only read.
