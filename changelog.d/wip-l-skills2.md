- Settings has a Skills page in every Space, Personal and Team. Skills shared with you wait at the top as cards that say who shared it, what it does, what it can touch (scripts, tool servers, the internet, Vault keys) and where it came from. Add to my skills applies it to you and your agents; Not now leaves it out. Nothing shared runs for you before you add it.
- Mine lists your own skills and the shared ones you added. Each can be switched off, given to all your agents or only some, shared with chosen people or with everyone in the Space, updated from its link, or removed. Your agents section shows which skills each agent uses.
- From your Space lists the skills an admin set in Console. They apply to everyone and their agents with no card. You can read them and cannot remove them.
- Add a skill takes a link (a SKILL.md, a GitHub repo or a folder in one), a dropped folder or zip, a plugin from an allowed marketplace, or Ask the Assistant, which opens the Ask pane and installs it on your yes. Codex skill folders and a lone AGENTS.md are read too. Before anything is saved you see what each skill can touch.
- A skill that brings a tool server asks for its keys on the skill's page: Add to Vault saves the key in your Vault and the skill keeps only its name. A Test button shows whether the server answers and how many tools it has.
- When a person who shared a skill updates it so it can touch more, everyone who added it gets the card again and the skill stops running for them until they add it again.
- Two skills with one name are both kept. The one that came later is renamed with its source, such as "pdf (from acme/skills)", on the page and in every agent's list.
- Console, Skills is the admin's view: Space-wide skills (install, update, remove, keys), the members' own skills by name only, Make Space-wide on a skill a member shared, and a rule, off by default, that only admins add skills that run scripts or start tool servers.
