Every task now has its own thread, the one place for its work. The people and agents on a task (Assigned, Reviewer, Approver) are in it, and a new holder is added when a slot changes. Task threads do not show in Recent chats, and the agents in one run only when woken or mentioned.
Every work task now has baton tools an agent can call: task_submit, task_ask, task_block, task_review and task_decide. Submit hands in the outputs with a one-line summary, and the outputs are checked against the schema the task asks for. A reviewer approves or sends work back with numbered fixes, and after the review loop limit the decision passes to a person. An approver approves or rejects with a reason. A question opens an Answer task for the requester or a named person and the work waits on it; a block opens an Unblock task for whoever the task escalates to. Each hand-over is also written as a line in the task thread.
