- The desktop app on a Mac can host the Space itself: Create a Space, Team Space, "Run this Mac as the Space server". The shell starts a Team Space (`vyred --role space,device`) on a fixed loopback port with its own data folder, linked outward to the relay, and opens its owner setup link (or its sign-in if it is already claimed). It stops with the app and starts again at the next launch once set up. For a Mac that stays on, use the Mac installer.
