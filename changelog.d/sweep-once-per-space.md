The ten-minute project folder sweep no longer runs in full at every tick: it ran again each time because its "already swept" memory was kept per database handle, and a job gets a new handle on every run. On a Space of 40,000 records that was about 70 seconds of blocks of 1.5 to 3 seconds every ten minutes. It now runs once per start and after that only when there is work, and a folder that already follows its record is answered without loading or rebuilding the access view.
