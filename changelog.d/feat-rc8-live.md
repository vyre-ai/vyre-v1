Folders you mount from Google Drive, OneDrive and SharePoint are now live. The folder at the provider stays the source of truth: Vyre shows its tree and details at once and fetches a file's content when you open it, then keeps it until the file changes there. A new cloud mount is live; "Synced copy" is still a choice, and mounts you already have keep their mode. Changes at the provider arrive as they happen when this server has a public address (a Drive watch channel or a Graph subscription, replaced before it expires), and otherwise every 30 seconds while an app is showing the folder and every 5 minutes after. Writes are conditional on the version they were based on: if the file changed at the provider in the meantime, Vyre never overwrites it. Your edit goes up beside it as "Report (Maya's edit).docx" and the mount reports a conflict. Version history comes from the provider (Drive revisions, OneDrive and SharePoint versions) with Restore, and an edit sent from Vyre is noted with the person or agent who made it. Each file carries the provider's last editor and time.
