The reply is labelled as their routine. Run Now makes the agent act the same way. A routine that missed runs while the server was off runs once when it comes back, not once for every missed time. Only the computer that runs scheduled work fires routines.

Chats and channels named in a routine's instructions show as their names, as links. One Next line sits under the title ("Next: today 09:12").
- Watchers act. A new message in the channel a watcher listens to wakes its agent. The message is in the agent's input and its answer goes in the same thread, once. The agent's own posts and routine posts never set a watcher off.
- A routine's run is finished when the agent's turn ends: done, failed or stopped, with the turn linked. The routine's Last run says how it went ("Done 2 min ago").
