A Flow now gets the record: a form, a button, a stage move and a record change each carry `trigger.record` (its fields, sealed ones left out), so `{{trigger.record.email}}` fills. A trigger filter that names a key its trigger does not have (`recordType` on a form, `field` on a record change) is refused when it is saved, with the key to use instead. Every `{{ }}` is checked when the Flow is saved and when it runs: an unknown one is an error that names it and the nearest valid one, and a step that meets one fails instead of sending an empty value.
