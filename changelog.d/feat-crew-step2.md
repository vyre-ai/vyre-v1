- Crew, step 2: a lead agent starts, lists, messages, stops and merges teammates with the `crew_*` tools. When a teammate finishes, its leftovers are committed and one result card (a `crew_result` block, with the commits, the files and the teammate's last words) arrives in the lead's chat as a message from the teammate that names the lead, which wakes the lead the ordinary way. The card does not count as a hop between agents, so a crew working while nobody is at the keyboard is not stopped after a few results. People and the lead can write in a teammate's own thread. Merge lands the branch in the project repository; a person's press runs, an agent's request holds at the Gate. A brief from one agent to another now names the receiver, and an agent's message carries the person it speaks for, so the engine can read a thread nobody has spoken in yet.
