- A mount of Google Drive, SharePoint or OneDrive now syncs as the person who made it, not as whoever runs the pass (before, a pass run by an admin or the scheduler read the wrong person's Drive or failed). A Drive mount also takes the changes feed's start token before its first listing and reads only the feed afterwards, instead of rescanning the whole folder every time. New: google.dwd.my_account and ms.consent.my_account name the address the caller is matched to.
