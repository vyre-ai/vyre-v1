A Vault key now has a clear path to an Automation step. A key, env block or login shows Add to Automations in the Vault. It starts a chat with your assistant on your own AI account, with the app name, the Vault handle (never the value) and the new connector-builder skill. The agent finds the app's API docs, drafts actions and triggers through the live connector API, runs one safe test read, shows a review card and waits for you to publish. A published connector then shows in the step picker under Your connectors, one step per action, already pointing at its connection. Under the button the Vault lists the Automations that use the key, and each opens. In the HTTP step, a key picked from the Vault also names the other steps that use it. The Automations start page offers Set up for a newly saved key, and offers are made only for keys, env blocks, logins and loose items. If there is no AI account, the account needs signing in, the Vault is unreachable or you can only view the item, a short notice with a fix button replaces the error. New capability: automations.vault_usage (generated files need regenerating).
