# Previews (previews)

Lane L4. Kind module. Version 0.1.0.

Requires: nothing.

## Capabilities (6)

- [previews.get](../capabilities/previews.get.md): Get the preview of one file version at a size, or one page of it
- [previews.health](../capabilities/previews.health.md): The converter answers on a tiny sample file and the queue is short
- [previews.pages](../capabilities/previews.pages.md): Page images of a PDF or Office file
- [previews.render](../capabilities/previews.render.md): Make or remake the preview of a file version (system; also run by the consumer after every new version)
- [previews.text](../capabilities/previews.text.md): Extracted text of a PDF, Office, image-free or plain file, for the viewer, search and agents
- [previews.thumbnails](../capabilities/previews.thumbnails.md): Thumbnails for a grid of files in one call

## Events (2)

- [preview.failed](../events/preview.failed.md): A preview could not be made; the file still opens as a download
- [preview.ready](../events/preview.ready.md): Thumbnails, page images or text were made for a file version
