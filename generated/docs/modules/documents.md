# Documents (documents)

Lane L4. Kind module. Version 0.1.0.

Requires: files.

## Capabilities (8)

- [documents.fields](../capabilities/documents.fields.md): List the fields a template needs (its {blanks})
- [documents.fill](../capabilities/documents.fill.md): Fill a template into a new file in a folder
- [documents.make](../capabilities/documents.make.md): Make a document for a record from a template
- [documents.make_pdf](../capabilities/documents.make_pdf.md): Make a PDF of a .md document in a folder; names any blank left
- [documents.mark_template](../capabilities/documents.mark_template.md): Mark a .docx or .md file as a template, or unmark it
- [documents.preview_fill](../capabilities/documents.preview_fill.md): Preview a filled template: what is missing or unused
- [documents.signing](../capabilities/documents.signing.md): Where the signers of a PDF made from a Vyre document sign, and what it was filled from
- [documents.templates.list](../capabilities/documents.templates.list.md): List templates

## Events (2)

- [document.filled](../events/document.filled.md): A document was made by filling a template
- [document.template_marked](../events/document.template_marked.md): A file was marked or unmarked as a template
