Requires: nothing.

- [templates.install](../capabilities/templates.install.md): Install a template (install sheet shown first)
- [templates.list](../capabilities/templates.list.md): Gallery of template packages
- [templates.preview](../capabilities/templates.preview.md): Preview what a template adds before installing
- [templates.project_starters](../capabilities/templates.project_starters.md): Starters for New project and New Journey type, an empty one first
- [templates.save](../capabilities/templates.save.md): Save an agent, Automation, Journey, record type, runbook or project as a template
