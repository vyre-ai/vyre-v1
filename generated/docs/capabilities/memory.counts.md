# memory.counts

Counts for the agent strip: current facts, proposed facts, facts from the caller and facts merged on their own

| | |
|---|---|
| Module | memory |
| Version | 1 (since 1.0.0) |
| Effects | read |
| Permission | grant only |
| Grant level | view |
| Risk | low |
| Resource | space |
| Gate | none |
| Idempotency | natural |
| Offline | online |
| Audit | none |
| Team Space only | no |
| HTTP | POST /v1/memory/counts |
| MCP tool | memory_counts (memory) |
| CLI | none |
| Emits | none |

## Input

```ts
type In = {
  agentId: string;
};
```

## Output

```ts
type Out = {
  current: number;
  proposed: number;
  fromMe: number;
  autoMerged: number;
};
```

## Errors

- internal.unexpected
- permission.above_clearance
- permission.no_grant
- validation.bad_input

## Example

```json
{
  "name": "example",
  "input": {
    "agentId": "agt_a1b2c3"
  },
  "output": {
    "autoMerged": 1,
    "current": 1,
    "fromMe": 1,
    "proposed": 1
  }
}
```
