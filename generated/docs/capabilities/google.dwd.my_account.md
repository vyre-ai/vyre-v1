# google.dwd.my_account

The Workspace address the caller is matched to, if any (a Drive mount names it so it syncs as the person, not as an admin)

| Module | google |
| Version | 1 (since 1.0.0) |

| Permission | grant only |

| Risk | low |
| Resource | space |
| Gate | none |
