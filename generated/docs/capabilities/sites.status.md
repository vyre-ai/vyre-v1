## Input

```ts
type In = {
  siteId: string;
};
```

## Output

```ts
type Out = {
  answering: boolean;
  detail?: string;
  url?: string;
  live: boolean;
  blocked: boolean;
};
```

## Errors

- internal.unexpected
- permission.above_clearance
- permission.no_grant
- validation.bad_input
- validation.not_found
