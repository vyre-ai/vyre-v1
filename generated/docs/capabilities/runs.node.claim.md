# runs.node.claim

Take a queued node for a worker: queued to running with a lease; returns the node, or none when it was not free

| | |
|---|---|
| Module | runs |
| Version | 1 (since 1.0.0) |
| Effects | write |
| Permission | grant only |
| Grant level | edit |
| Risk | medium |
| Resource | space |
| Gate | none |
| Idempotency | natural |
| Offline | online |
| Audit | none |
| Team Space only | no |
| HTTP | POST /v1/runs/node/claim |
| MCP tool | none |
| CLI | none |
| Emits | run.node_state |

## Input

```ts
type In = {
  runId: string;
  holder: string;
};
```

## Errors

- internal.unexpected
- permission.above_clearance
- permission.no_grant
- validation.bad_input
